# Verificacao do pacote

Testado em 07/10/2026 neste computador, em um projeto Docker separado do banco de trabalho.

- Imagens de frontend e backend compiladas em Linux no Docker.
- PostgreSQL 18 inicializado com a copia do banco; migracoes Flyway validadas.
- Os tres servicos ficaram saudaveis.
- Acesso a interface e as APIs pelo endereco local do pacote confirmado.
- Conferidos 32 materiais, 986 roteadores, 17 tecnicos e 52 movimentacoes.
- Saldo total de materiais: 1588; MANTA 65/19-150: 40.
- Script de backup executado tambem no Windows PowerShell usado pelos atalhos.
- Backup restaurado com sucesso em outro banco temporario; contagens conferidas.
- Scripts de instalacao e agendamento passaram pela verificacao de sintaxe. O agendamento nao foi ativado neste computador.

A compatibilidade do PC da empresa com Docker Desktop e Windows 10 ainda precisa ser conferida. Nenhum teste foi executado naquele PC.
